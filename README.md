# node-postgres-prisma

Practical examples exploring Node.js data access with PostgreSQL and Prisma (and related ORM samples in-tree).

## What’s here

- Prisma-oriented examples (`prismaExample`, etc.)
- Companion samples for comparison (e.g. Sequelize folder)

## How to use

Open the example folder you care about, follow its local README or `package.json` scripts, and run against a local Postgres instance. Prefer synthetic / local credentials only.

## Status

Reference / learning — not a hosted production service.
